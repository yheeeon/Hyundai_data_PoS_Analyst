## 1. 프로젝트 개요

국내 자동차 시장에서 친환경차 전환 속도는 지역마다 다르다. 그러나 월별 등록 통계는 엑셀 파일과 시트별로 흩어져 있고, 현대차 판매 구성과 함께 비교하려면 매번 수작업 집계가 필요했다.

이 프로젝트는 이 반복 작업을 자동화해 상품기획·마케팅 담당자가 다음 질문에 바로 답할 수 있는 모니터링 대시보드를 만드는 것을 목표로 했다.

- 어느 지역에서 친환경차 전환이 빨라지고 있는가?
- 현대차의 국내·수출 판매 구성은 어떤 파워트레인과 모델에 집중되어 있는가?
- 지역 시장의 전환 수준과 현대차 판매 포트폴리오를 함께 검토할 때 추가 분석이 필요한 영역은 어디인가?

## 2. 데이터와 분석 기준

### 데이터

| 데이터 | 단위 | 용도 |
| --- | --- | --- |
| 국토교통부 자동차 등록 통계 | 기준월 × 지역 × 연료 × 차종 × 용도 | 지역별 시장 규모와 친환경차 등록 구조 |
| 현대자동차 IR 판매 통계 | 판매월 × 국내·수출 × 카테고리 × 모델 | 현대차 파워트레인·모델 판매 구성 |

등록 데이터는 특정 시점에 등록된 누적 보유 규모이고 판매 데이터는 해당 기간의 판매 발생량이다. 따라서 두 값을 직접적인 시장점유율로 계산하지 않고, **친환경차 구성비와 변화 방향을 비교하는 참고 지표**로 사용했다.

친환경차는 `EV + HEV + FCEV`로 정의했다. 현대차 판매 데이터의 `PHEV`는 원천 데이터에 존재할 경우 별도 파워트레인으로 표시하고 친환경차 합계에는 포함하지 않았다.

### 전처리

- 파일명에서 기준 연도·월 자동 추출
- 원본 엑셀의 병합 셀 값 보정
- 제목 행과 실제 헤더 행을 조건으로 탐색
- 콤마가 포함된 숫자와 `-` 값 정리
- 소계·총계 행 제거
- 세부 연료명을 `EV`, `HEV`, `FCEV`, `Gasoline`, `Diesel`, `LPG` 등으로 표준화
- 모델명에서 모델 패밀리와 파워트레인 파생
- 날짜·지역·연료·차종·모델을 차원 테이블로 분리하고 등록·판매 사실 테이블 생성

## 3. 핵심 지표

### 지역별 전환 속도

```text
지역 친환경차 비중 = (EV + HEV + FCEV 등록대수) / 지역 전체 등록대수 × 100
전환 속도 = 현재월 친환경차 비중 - 이전 기준월 친환경차 비중
```

현재 대시보드는 지역별 현재 비중, 전월 대비 증감폭, 시장 등록 규모를 함께 보여준다. 따라서 비중은 높지만 정체된 지역과, 비중은 아직 낮아도 빠르게 상승하는 지역을 구분할 수 있다.

### 현대차 판매 구성

```text
현대차 친환경 판매 구성 = (EV + HEV + FCEV 판매대수) / 선택 시장 전체 판매대수 × 100
```

국내·수출 필터에 따라 파워트레인 구성과 판매 상위 모델을 분리해서 확인한다.


## 4. 분석 결과


### 4.1 전국 친환경차 시장은 확대되고 있다

| 기준 | 친환경차 등록 비중 |
| --- | ---: |
| 2023년 | 7.23% |
| 2024년 | 9.34% |
| 2025년 | 11.88% |
| 2026년 7월 | 15.11% |

2023년 7.23%에서 2026년 7월 15.11%로 7.88%p 상승했다. 친환경차 전환은 특정 모델이나 특정 지역의 단기 현상보다 지속 추적할 구조적 변화로 볼 수 있다.

### 4.2 지역별 전환 속도와 수준은 다르다

2026년 6월 대비 2026년 7월 전환 상승폭이 큰 지역은 대구(+0.43%p), 제주(+0.42%p), 부산(+0.42%p), 인천(+0.38%p) 순이었다.

현재 친환경차 비중이 높은 지역은 제주(25.58%), 인천(20.73%), 부산(18.95%), 세종(18.30%)이다. 따라서 “현재 비중이 높은 지역”과 “이번 달 전환이 빠른 지역”을 같은 기준으로 보지 않고 분리해서 해석해야 한다.

### 4.3 현대차 판매에서도 친환경차 비중이 높다

2026년 7월 현대차 판매 구성은 다음과 같다.

| 판매시장 | 전체 판매 | 친환경차 판매 구성 |
| --- | ---: | ---: |
| 국내 | 46,811대 | 40.00% |
| 수출 | 89,581대 | 41.32% |

파워트레인별로는 국내에서 ICE 60.00%, HEV 27.70%, EV 10.25%, FCEV 2.05%였고, 수출에서는 ICE 57.44%, HEV 30.61%, EV 10.70%, FCEV 0.01%, PHEV 1.23%였다.

### 4.4 국내와 수출의 주력 모델은 다르다

2026년 7월 국내 상위 모델은 Grandeur, LCV, Santa-Fe, Sonata, Kona 순이었다. 수출 상위 모델은 Avante, Kona, Tucson, Palisade, Sonata 순이었다.

따라서 국내와 수출을 합산한 판매 순위만으로 상품 방향을 정하면 시장별 차이를 놓칠 수 있다. 국내는 대형·상용·고급 수요, 수출은 Avante·Kona·Tucson 등 글로벌 주력 모델을 별도로 확인해야 한다.

## 6. 의사결정 활용

이 분석은 특정 차종 출시를 자동으로 결정하는 모델이 아니라 다음 분석의 우선순위를 좁히는 모니터링 도구다.

- 전환 속도가 빠르고 현재 비중도 높은 지역: 충전 인프라·보조금·렌터카 수요를 확인하고 친환경 라인업 대응 검토
- 현재 비중은 높지만 전환 속도가 둔화된 지역: 성장성보다 경쟁사와 가격·채널 점검
- 전환 속도는 빠르지만 비중이 낮은 지역: 초기 수요인지 일시적 변동인지 다음 월에도 확인
- 국내·수출의 파워트레인 또는 모델 구성이 다른 경우: 시장별 상품·마케팅 전략 분리

가격, 경쟁사 판매량, 충전 인프라, 보조금, 현대차 지역별 판매 데이터를 추가하면 지역·제품별 우선순위를 더 정확하게 산출할 수 있다.
